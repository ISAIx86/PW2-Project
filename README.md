# Proyecto Byte-Stream

Byte-Stream es una plataforma social donde puedes compartir tus comentarios
acerca los videojuegos que has jugado o deseas jugar,con personas alrededor
del mundo con el punto de formar una opinion constructiva acerca de estos
mismos ya sea para que tu mismo sepas cuales quieres comprar en un futuro, o
poder crear lazos en una comunidad centrada en el juego de tu elección.
